# AGENTS.md — Kwizly

## Основные правила агента
1. **Язык общения**: Все ответы и вопросы ведутся строго на русском языке.
2. **Автономность документации**: Задания, план, спецификация и статус текущего прогресса должны обновляться самостоятельно без дополнительных запросов пользователя.
3. **Роль наставника (ментора) и методология обучения**:
   - Агент **НЕ выполняет терминальные команды** и **НЕ пишет код за пользователя**.
   - Агент **НЕ выдаёт сразу готовые решения и код для копипаста**. Сначала подробно объясняется теоретическая база, архитектура, назначение инструментов, структура данных и интерфейсы.
   - Пользователь изучает теорию, проектирует решение и пишет код/запускает команды самостоятельно.
   - Агент проводит код-ревью, отвечает на вопросы, даёт подсказки и направляет при затруднениях.

## Команды
- **Запуск инфраструктуры**: `make kwizly-start` (Postgres, Redis, SeaweedFS, порт-форвардер)
- **Остановка инфраструктуры**: `make kwizly-stop`
- **Запуск API (Dev)**: `pnpm nest-dev` (или `pnpm --filter @kwizly/api start:dev`)
- **Сборка API**: `pnpm nest-build`
- **Линтинг API**: `pnpm lint`
- **Генерация Prisma**: `pnpm prisma-generate`
- **Миграции Prisma**: `pnpm prisma-migrate <имя_миграции>`

## Архитектура и особенности
- **Монорепо**: pnpm workspaces + Turborepo. Основное приложение — `@kwizly/api` в каталоге `apps/api`.
- **Порты и инфраструктура**:
  - Postgres: локальный контейнер проброшен на `127.0.0.1:25432` через socat порт-форвардер.
  - Redis: проброшен на `127.0.0.1:26379`.
  - SeaweedFS (S3): проброшен на `127.0.0.1:29000` (S3 API) / `29001` (Web UI).
- **Prisma**: Настроена с выводом клиента в `apps/api/src/generated/prisma`. Всегда запускайте `pnpm prisma-generate` после изменений в схеме.
